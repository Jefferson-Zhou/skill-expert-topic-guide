# Output Templates

Stable output formats for the expert topic guide. Use these as the structural backbone — adapt content to the specific topic and user.

## Template 1: Full Learning Guide (Default)

Use when the user asks for a complete guide to an unfamiliar topic.

```markdown
## Quick Assessment

[One sentence: what this topic is, why it matters now, and where learners typically get stuck.]

## Topic Map

| Layer | Content |
|-------|---------|
| Object | [What this topic studies/builds/operates on] |
| Problem | [What challenges it addresses] |
| Concepts | [Core terms + relationships + common confusions] |
| Mechanism | [How it works — processes, loops, causal chains] |
| Methods | [Approaches, tools, frameworks, evaluation] |
| Practice | [Real applications, projects, benchmarks, metrics] |
| Controversy | [Open questions, failure modes, overhyped claims] |

## Learning Path

### 1-Hour Path
- Goal: [what you'll be able to do]
- Do: [specific actions]
- Read: [1-2 resources with roles]
- **Minimum action**: [ONE concrete task <30 min that produces a tangible artifact]

### 1-Day Path
- Goal: [what you'll be able to do]
- Do: [specific actions]
- Read: [3-5 resources with roles and sequence]
- **Minimum action**: [ONE concrete task <2 hours that produces a tangible artifact]

### 1-Week Path
- Goal: [what you'll be able to do]
- Do: [specific actions including a project]
- Read: [core materials with roles]
- **Minimum action**: [ONE concrete deliverable that proves you've reached the goal]

### 1-Month Path
- Goal: [what you'll be able to do]
- Do: [substantial project or research]
- Read: [deep materials for chosen sub-direction]
- **Minimum action**: [ONE concrete deliverable that proves you've reached the goal]

## Resources

### Introductory (build vocabulary and intuition)
- [Resource] — Role: [why read this]. Effort: [time estimate].

### Authoritative (establish correct understanding)
- [Resource] — Role: [why read this]. Effort: [time estimate].

### Practical (enable hands-on work)
- [Resource] — Role: [why read this]. Effort: [time estimate].

### Frontier (current state and open problems)
- [Resource] — Role: [why read this]. Effort: [time estimate].

### Pitfall-Avoidance (common mistakes and misconceptions)
- [Resource] — Role: [why read this]. Effort: [time estimate].

## Practice Tasks

| Stage | Task | Pass Criteria |
|-------|------|---------------|
| Entry | [task] | [how to know you're done] |
| Basic | [task] | [how to know you're done] |
| Intermediate | [task] | [how to know you're done] |
| Advanced | [task] | [how to know you're done] |

## Checkpoints

Test your understanding with these questions:

1. [Concept discrimination question]
2. [Mechanism explanation question]
3. [Method comparison question]
4. [Judgment/evaluation question]
5. [Counter-example/boundary question]
6. [Design/application question]

## Next Steps

Based on your goal of [stated goal]:
- Immediate action: [what to do right now]
- This week: [short-term target]
- Decision point: [what to evaluate after initial learning]
```

## Template 2: Quick Overview (1-Hour Budget)

Use when the user has limited time or just wants orientation.

```markdown
## What This Is

[2-3 sentences: object, problem, why it matters]

## Key Concepts

[5-8 concepts with one-line explanations and relationships]

## How It Works

[Core mechanism in 3-5 sentences or a simple diagram description]

## Where to Start

1. [First resource — 15 min]
2. [Second resource — 20 min]
3. [Quick exercise — 15 min]

## Common Confusions

- [X is NOT Y because...]
- [People often think Z, but actually...]

## Quick Check

Can you answer these?
1. [Question 1]
2. [Question 2]
3. [Question 3]
```

## Template 3: Expert Transfer (Adjacent Field)

Use when the user has deep expertise in a related area.

```markdown
## Translation from Your Field

| In [your field] | In [new field] | Key difference |
|-----------------|----------------|----------------|
| [concept A] | [equivalent] | [what's different] |
| [concept B] | [equivalent] | [what's different] |

## What Your Intuition Gets Right

- [transferable insight 1]
- [transferable insight 2]

## Where Your Intuition Will Mislead You

- [trap 1: why your existing mental model breaks here]
- [trap 2: why your existing mental model breaks here]

## Fast Track

Since you already understand [X, Y, Z], skip the basics and go directly to:
1. [Advanced resource focused on the delta]
2. [Key paper/doc that addresses the non-obvious differences]
3. [Project that forces you to confront the differences]

## Core Controversies

[What experts in this field argue about — this is where the real learning happens for someone at your level]
```

## Template 4: Research Entry

Use when the user's goal is academic research.

```markdown
## Field Overview

[What this research area studies, its relationship to adjacent fields, current momentum]

## Research Landscape

### Key Venues
- [Conference/journal 1] — focus: [what they publish]
- [Conference/journal 2] — focus: [what they publish]

### Major Groups
- [Lab/team 1] — known for: [contribution]
- [Lab/team 2] — known for: [contribution]

## Literature Map

### Anchor Papers (define the field)
- [Paper] — Role: [why it matters]

### Reviews (entry points)
- [Paper] — Role: [what it covers]

### Method Papers (by sub-direction)
- [Sub-direction 1]: [Paper 1], [Paper 2]
- [Sub-direction 2]: [Paper 1], [Paper 2]

### Benchmarks
- [Benchmark] — measures: [what], status: [active/outdated]

### Critiques
- [Paper] — challenges: [what assumption]

## Active Debates

1. [Debate 1: position A vs. position B]
2. [Debate 2: position A vs. position B]

## Entry Points for New Researchers

- Accessible open problems: [list]
- Replication opportunities: [list]
- Cross-disciplinary bridges: [list]
- Gaps in current literature: [list]
```

## Formatting Rules

- Use tables for structured comparisons
- Use bullet lists for sequences and enumerations
- Keep each section scannable — no walls of text
- Bold key terms on first use only
- Include time estimates for all recommended resources
- Every resource recommendation must have a stated role
